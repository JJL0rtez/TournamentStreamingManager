# Tournament Streaming Manager v15

- Tournament session event name and permanent ID share one responsive row.
- Ring names and camera hardware names appear together in camera cards and quality selection.
- Camera microphone selection resolves stable saved device IDs, saved exact names, or unique name matches for built-in microphones. Ambiguous matches must still be selected manually.
- Recording Drive capacity and write speed appear inline, with only advanced assumptions folded away.
- Consistent charcoal/gray, white, gold and red theme and collapsed-panel spacing.
- UI changes are cumulative with v14, and no server settings are modified in v15.

Run npm run typecheck, npm run build and npm run test:all from the project root.
